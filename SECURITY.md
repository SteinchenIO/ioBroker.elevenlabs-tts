# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitskorrekturen gibt es für die jeweils neueste Version.

## Sicherheitslücke melden

Bitte melde Sicherheitslücken **nicht** öffentlich als Issue.

Nutze stattdessen die private Meldung von GitHub (Reiter "Security" > "Report a vulnerability") oder schreibe an **git@felz.de**.

Beschreibe bitte kurz, was passiert, wie man es nachstellen kann und welche Version betroffen ist. Ich antworte so schnell wie möglich.

## Hinweise zum API-Key

- Der ElevenLabs-API-Key wird verschlüsselt in der Instanzkonfiguration gespeichert.
- Gib den Key nie in Issues, Protokollen oder Screenshots preis. Falls das doch passiert ist, lösche den Key bei ElevenLabs und erstelle einen neuen.
