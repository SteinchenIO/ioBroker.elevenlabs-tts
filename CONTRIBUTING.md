# Mitarbeit an ioBroker.elevenlabs-tts

Danke, dass du helfen möchtest! Fehlermeldungen, Ideen und Pull Requests sind willkommen.

## Fehler melden

1. Prüfe unter [Issues](https://github.com/SteinchenIO/ioBroker.elevenlabs-tts/issues), ob der Fehler schon gemeldet wurde.
2. Öffne ein neues Issue und nutze die Vorlage "Fehlermeldung".
3. Hänge das Protokoll der Instanz an (Log-Level `debug`, wenn möglich).

**Wichtig:** Gib niemals deinen ElevenLabs-API-Key weiter. Im Protokoll und in Screenshots den Key vorher unkenntlich machen.

## Idee oder Wunsch

Öffne ein Issue mit der Vorlage "Funktionswunsch" und beschreibe, was du erreichen möchtest und warum.

## Pull Requests

1. Forke das Repository und erstelle einen Branch (z. B. `fix/kurze-beschreibung`).
2. Halte dich an den vorhandenen Stil in `main.js`.
3. Prüfe die Syntax mit `npm run check`.
4. Teste die Änderung in einer ioBroker-Instanz (Text in `elevenlabs-tts.0.speak` schreiben, MP3 und `newFile` prüfen).
5. Beschreibe im Pull Request, was sich ändert und wie du es getestet hast.

Ein Pull Request sollte eine Sache ändern. Mehrere unabhängige Änderungen bitte getrennt einreichen.

## Lizenz

Mit deinem Beitrag stimmst du zu, dass er unter der [MIT-Lizenz](LICENSE) des Projekts veröffentlicht wird.
